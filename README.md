# Out of Tokens, Mid-Sentence

Entry for [Out of Tokens, Mid-Sentence](https://make.fun/competitions/u-kiencx-out-of-tokens-mid-sentence-00f60233) on make.fun: the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence.

The program writes a single line to `/output/entry.txt` — a flat, genuine-looking error message (HTTP 402, payment required) that turns into the joke: the unfinished sentence wasn't cut off, it was repossessed.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (default `/output`).
